## P0-M1 · 上游导入与环境

**前置与必要读取：**无前置开发模块。读取[参考资料](../../REFERENCES.md)、[项目结构](../../PROJECT_STRUCTURE.md)、根 README；检查工作区是否已有用户新增代码。

**执行提示词：**以已研究快照建立本地上游基线，导入 Python 源码、必要配置和测试并保留版权及许可。使用临时检出或下载区核实内容，不覆盖当前项目文档、本地 `Aseprite/` 或用户变更；上游 README 的安装与功能信息按需合并到后续说明，而非替换根 README。

- 实现：默认核实并导入提交 `90d1696a7e41edff89bbd0823ae6a5f86c114bcc`；建立 Python 3.13+ 的 `uv` 环境、依赖锁及配置示例。通过 `ASEPRITE_PATH` 使用用户准备的软件，检查 Unicode 路径。建立正式测试说明和贡献入口，说明环境、测试分层、模块交接和提交约定。
- 来源与仓库：建立 `LICENSE` 和第三方来源记录，保留上游原始声明；建立 `.gitignore`，排除本地软件、个人配置、恢复文件、凭据及构建输出。检查具体规则，不以全局忽略图片方式排除测试资源。不在此任务中自行创建远程地址。
- 接口/兼容：首个基线保留上游 CLI 工具语义；依赖以实际导入版本为准。将实际导入 SHA、目标与实际解释器版本、配置方法、测试命令写入文档。当前 Python 3.12 不得被记录为满足开发要求。
- 失败与边界：快照不可取得、许可不一致、依赖失败或已有同名文件冲突，记录原因并保留用户内容；需要改用其他版本时先说明差异并更新计划。上游测试的固定 `/tmp` 路径须在副本中改为平台兼容夹具，保持测试语义；明确区分原基线失败和本次适配引入的失败。
- 验收：验证实际 Python 为 3.13+、锁定依赖可同步、包可导入、工具可枚举；用真实 Aseprite 在临时目录创建、读取和导出文件，复跑适用的上游基线测试。记录实际命令、用例数量、失败/跳过原因及中文路径结果，不能只做 Python 编译检查。记录入库文件清单，确认没有本地软件和个人数据。

**交接与状态：**实际执行后写 `docs/progress/P0-M1.md`，同步[阶段总结](../../progress/P0.md)、[根计划](../../../EXECUTION_PLAN.md)、结构、来源和环境记录。模块报告当前未生成；全部验收通过才勾选。仓库尚未初始化时如实记录未提交，不为提交而擅自初始化。

**下一步：**[P0-M2](#p0-m2)，以已导入工具和真实基线拆分双后端契约；基线失败先修复或准确界定阻塞，不直接开始实时功能。

## P0-M2 · 双后端边界及接口约定

**前置与必要读取：**P0-M1 已验收；读取其实际报告、[架构说明](../ARCHITECTURE.md)，以及导入后的命令执行器、画布、绘图和导出实现。

**执行提示词：**建立操作与结果模型、后端能力接口及一条可运行的 CLI 适配路径。分离参数转换、图像算法与文件加载/保存，避免为了抽象一次重写全部上游工具。首版工具目标和限制沿用架构说明。

- 实现：确定实时核心与上游 CLI 工具的暴露配置；冻结协议版本、握手、会话/文档/图层标识、请求关联、预期修订、批次内新图层引用、结果/错误结构和 PNG 传输约定。默认 stdio；内部服务使用回环地址及启动会话校验。为消息大小、单批操作数、像素数、超时及去重缓存设置明确可配置上限并说明默认值依据。
- 最小纵向路径：通过公共执行接口完成一次 CLI 文档信息读取和一次临时文件绘制，复用实际代码验证抽象；不要求此模块接通尚未实现的实时后端。
- 接口/兼容：帧号从 1 开始、画布坐标、RGBA 0–255；明确缺省值、越界拒绝及不支持能力的错误。通过 JSON 序列化传参，避免新增不受控 Lua 字符串拼接。保持已有 CLI 工具调用兼容，新增实时工具使用独立名称及显式目标。
- 失败与边界：无连接不自动转 CLI；畸形消息、修订冲突、无效对象、执行失败及结果未知有独立结果。CLI 用例确认脚本失败和“退出 0 但无产物”不会被当作成功，已有输出文件也不能作为本次成功的证据。
- 验收：契约测试覆盖正常请求、校验失败、未知能力、会话/版本不兼容及错误映射；真实 CLI 路径在临时目录读写并核对像素。运行受影响上游回归，并记录哪些契约仅由模拟后端验证。更新架构文档为明确类型、样例及实施位置。

**交接与状态：**实际执行后写 `docs/progress/P0-M2.md`（当前未生成），同步阶段总结、根计划及结构。默认已验收模块本地提交，不推送；无 Git 时记录实际原因。

**阶段集成验收：**依照新文档从依赖同步、配置 Aseprite、导入服务、枚举工具，到临时 CLI 读写完整执行一次；确认现有基线不因执行抽象退化，核心协议示例可通过校验。若失败，相关模块保持或退回未勾选。

**下一步：**阶段集成通过后进入 [P1-M1 · 扩展连接](P1-实时核心闭环.md#p1-m1)，实现刚冻结的握手和消息往返。
