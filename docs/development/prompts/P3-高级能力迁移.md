# P3 · 高级能力迁移

先读[执行约定](../README.md)、[P3 总结](../../progress/P3.md)及必要前置交接。阶段目标：在稳定核心上按需迁移上游高级能力，每组功能具有明确后端支持和回归证据。

共通边界：P2 首版集成已验收；P3 不阻塞首版发布。启动时上游和用户需求可能变化，因此先核实、列清单，再冻结批次；本文件不把研究时工具数当作必须全部实现的目标。

<a id="p3-m1"></a>
## P3-M1 · 上游工具兼容清单

**前置与必要读取：**P2-M2 及 P2 集成已验收；读取实际报告、当前来源记录、已有工具注册和测试、核心能力模型与已知限制。

**执行提示词：**重新核实上游实际版本和工具集，比较导入基线及后续变更，形成高级能力的兼容矩阵和可执行迁移批次。核实不自动等于升级，继续以当前已验收版本工作。

- 实现：按动画、调色板、特效、Tilemap 等能力组分类，逐项记录当前工具名、CLI 状态、实时可行性、最低 API、活动状态依赖、保存副作用、撤销适配、模拟/真实测试和来源许可；区分可直接复用、需解耦、需重写和不迁移。
- 批次决策：按用户价值及已具备依赖排序，默认先考虑常规帧/标签/时长，再考虑调色板与特效，Tilemap 后置；具体范围以复核结果写入迁移清单。每批应有清楚输入、输出、失败规则和验收，不把全部高级工具放进一个无边界任务。
- 接口/兼容：保持核心工具稳定，高级能力通过显式能力集启用；需要升协议或最低 Aseprite 版本时先记录迁移理由和旧版本行为。工具采用已有后端语义，不暗中把 CLI 文件操作变为实时操作。
- 失败与边界：上游移除或更名、许可不明、当前版本不支持或无法真实验证的能力标记原因，不承诺支持。无法复用的核心上下文假设须在清单中明确，不能仅以 Lua 函数存在作为迁移完成。
- 验收：清单对照实际工具注册和实现，无漏记已启用高级能力；抽查每组至少一个工具的路径、版本证据、保存/撤销影响与测试。把下一批任务细化到可直接执行并通过检查，而不是仅提交分类表。

**交接与状态：**执行后写 `docs/progress/P3-M1.md`（本模块交付生成），同步[阶段总结](../../progress/P3.md)、根计划、来源和结构。若单批无法独立验收，将 P3-M2 细化为首批，并追加稳定编号的后续模块及提示词；本阶段既定范围和验收边界必须写清，不能提前勾选未来模块。

**下一步：**[P3-M2](#p3-m2)，只实施清单中已冻结的首批；未冻结前先补齐清单与提示词，不直接迁移所有工具。

## P3-M2 · 按能力组迁移与回归

**前置与必要读取：**P3-M1 已验收；读取其实际报告、兼容清单、已冻结首批提示词以及对应上游工具和测试。已冻结清单见 [CAPABILITIES](../CAPABILITIES.md)，逐工具矩阵见 [tool-compatibility.json](../tool-compatibility.json)。P3-M2 只实施该清单的基础动画批次，默认能力关闭；输入、输出、失败、预算和验收均以冻结契约为准。

**执行提示词：**按照首批明确范围迁移算法和测试，拆开文件加载、活动对象、编辑和保存，接入现有后端及能力注册；不扩大到清单之外的功能。开始前先核实该批所需软件、测试资源及版本。

- 实现：优先复用已验证算法，补齐实时文档标识、修订、事务、预览与错误适配，保留 CLI 回归。只在该批全部验收后启用公开能力，并更新已支持工具清单。
- 接口/兼容：遵循已冻结接口；若复核发现必须修改核心契约，先记录影响、补充兼容方案及回归任务，再实施。不得为了一个高级功能静默改变核心工具的帧号、坐标或保存语义。
- 失败与边界：按批次覆盖缺失 Cel、图层偏移、关联 Cel、色彩模式或 Tilemap 等实际相关情形；不强迫每一批测试所有无关场景。未支持路径明确返回不支持，模拟结果不作为真实功能支持声明。
- 验收：为本批每个公开能力验证正常效果、错误输入、撤销/重做及预览一致性，分别记录 CLI 与真实实时模式结果；同时执行核心闭环回归。文档、能力注册和真实测试覆盖一致。

**交接与状态：**执行后写 `docs/progress/P3-M2.md`（本模块交付生成），同步阶段总结、根计划、结构和能力清单；已验收模块默认本地提交，不推送。若 P3-M1 已追加后续模块，报告必须链接到下一个实际模块与具体任务，不能笼统写“继续高级迁移”。

**阶段集成验收：**只有本阶段清单中明确纳入的全部批次完成，才集成验证核心闭环、各能力集组合、CLI 兼容及实际软件版本；失败退回相关模块。没有纳入的未来能力保持明确的后续范围，不以一个批次通过宣称全部高级能力已支持。

**下一步：**若有已创建的后续批次，进入其实际模块；若本阶段范围已完成，交接维护任务：上游差异复核、版本兼容回归及新增能力评估，均记录具体入口和未决事项。
