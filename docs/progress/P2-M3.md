## 实际完成了什么

Python 默认固定监听 127.0.0.1:8765；--host/--port 优先于环境与默认，localhost 规范化为 IPv4 回环，非回环地址/无效端口/拼写错误明确拒绝。create_server 支持显式 RuntimeConfig，stdio 与 console 入口共用配置。状态增加 automatic_discovery。

服务独占端口后，在用户运行目录按 host/port 原子发布本次随机 token/url；成功绑定后能替换强杀残留，端口占用不会覆盖凭据或换目标。正常退出仅清理本次所有权匹配的文件。显式 CONNECTION_FILE 继续独占创建；port=0 保留旧随机文件。

扩展启用后延迟启动 1 秒 Timer 等待服务；自动查找同一 host/port 的凭据，服务重启凭据变化自动重新握手。无需查状态拿路径、选择文件或在测试里调用 connect()。设置提供 Host/Port/自动连接；Disconnect 停用并保存偏好，手动恢复后重启 Timer；退出/重载释放自有连接、Timer、文档监听与对话框。旧 JSON 手选保留在 Legacy JSON 次级入口，使用时停用自动发现。

版本升至 0.2.0，协议 v1 业务契约不变；构建入口继续同时核对服务/扩展版本。独立安装脚本改用产品自动发现，删除凭据读取和连接参数注入，增加 30 秒客户端超时。所有 pytest 测试使用独立运行目录，不访问个人发现路径；没有改动个人 Aseprite 或客户端配置。

## 遗留与阻塞

无阻止本模块验收的问题。用户首次仍需接受 Aseprite 文件/回环权限提示；未代用户点击个人权限或安装扩展。其他平台未验证。默认多服务需要不同端口；同一个 Aseprite 配置目录被多个进程共用时，端口偏好也共用，可使用独立配置目录避免退出覆盖。同一 listener 仍只允许一个活动编辑器。自定义运行目录仅设置到 MCP 子进程时无法影响已打开编辑器，正常使用默认即可。旧临时文件不会被全盘扫描/删除。
