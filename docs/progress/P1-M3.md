## 实际完成了什么

新增 preview.lua，在独立 RGB Image 上用官方 drawSprite 合成指定帧/区域；RGBA 行进行整数最近邻复制，内存编码 PNG（CRC32、Adler32、存储型 deflate），不创建文件或临时 Sprite。PNG/像素/消息预算在分配和编码前后检查，超限提示缩小范围或缩放。editor 的既有目标/修订检查覆盖预览，源文档、活动上下文和历史不变。

get_preview 先校验 PngPayload 与 PNG 内容，再返回 MCP TextContent 元数据和 ImageContent，文字不重复携带 base64。补充 aftercommand 与活动状态/选区边界检查，覆盖同边界选区命令；插件 shutdown 同时清理对话框、socket、文档及应用监听器。

## 接口与兼容变化

协议 v1 不变，八种核心文档能力已协商；状态工具为第九入口。PNG region 总是给出实际源画布区域（未传区域时为完整画布），width/height 为缩放后尺寸。MCP get_preview 返回文字元数据 + 原生图片块，不返回文件路径。PNG 用无压缩 deflate，以明确大小界限换取无需磁盘或外部 Lua 库；超过默认 4 MiB/262144 像素需缩小范围。

## 遗留与阻塞

无阻止 P1 验收的问题。SDK 1.6.0 在 Windows 退出时强杀 stdio 子进程，无法执行服务 finally，可能留下发现 JSON；测试只清理自己的文件。正常 lifespan 退出清理已验证；固定发现路径残留时须确认旧服务已退出后移除该文件，默认每进程路径不重用。此退出策略和异常重连、外部文件覆盖竞态、安装打包/干净环境在 P2 系统验收。macOS/Linux 和其他客户端未验证。
