## 实际完成了什么

Executor 将执行任务与调用方等待分离，取消调用方仍保留已接收操作和回执；执行中相同 ID 合并、不同内容立即冲突。按 live 会话或规范化磁盘路径排队，有限队列和排队超时，旧会话完成不写入新缓存。迟到/重复回执不重放，未知写入不降级 CLI。默认发现文件加 UUID，固定路径冲突提供可行动诊断，不删除无法确认归属文件。

CLI 公共路径支持可选 expected_file_revision 和成功 data.file_revision，执行前/中检测文件变化。CLI 及旧 MCP 工具共享有期限线程锁，旧同步算法在线程运行。输出改为二进制捕获、调用线程严格解码；非零退出保留证据，超时清理本次进程与临时目录。核心 MCP 错误及图片校验错误使用结构化 Result/isError，旧工具常见失败文本同步标记错误。

实时事务累计检查 Cel 副本面积，并在单操作完成后检查 0.25 秒 CPU 预算，超限整批回滚；不拆批。stderr 仅记录后端、排队/执行耗时，预览 CPU 分离测量；无 token 或图像日志。

## 遗留与阻塞

无阻止本模块验收的问题。CLI 最终摘要检查与 os.replace 之间仍存在外部进程短竞态；旧高级工具未获得 nonce/原子提交契约，应独占文件，P3 再迁移。无法对任意外部进程强制加锁。SDK 强杀仍可留下发现文件，默认随机路径不会复用；固定路径确认旧进程退出后人工移除。未启用自动清理他人文件。
