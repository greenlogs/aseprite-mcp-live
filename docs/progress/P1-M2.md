## 实际完成了什么

新增 editor.lua，以对象相等比较维护会话文档/图层注册。枚举时移除已关闭对象和失效图层，不复用已分配编号；图层重名或重命名不影响定位。监听 Sprite change、图层属性/文件名事件和 app sitechange，分别维护内容与上下文修订。请求前再次核对目标、修订和可选上下文。

实现 list_documents、get_document_info、create_sprite、apply_operations、save_sprite、undo、redo。批次完整预检，再用 app.transaction 提交；独立图像修改后赋回 Cel，扩展图像边界保留偏移及画布外像素，空 Cel 按目标帧创建。临时目标切换在成功和失败后恢复原活动文档、图层及帧。保存只在显式工具中执行；只允许保留文档结构的 .aseprite/.ase，绝对路径、存在文件必须 overwrite=true。

## 接口与兼容变化

v1 线格式不变，协商扩充为七种文档动作。info/list 真实填写文档 ID、图层 ID、保存/修改状态、帧时长与活动上下文；create 返回新文档信息；apply 返回非空 layer_refs 及操作数；undo/redo 返回 applied，明确作用于目标的最新历史动作（包括人工操作）。revision 为事件计数而非批次数，回滚也可能推进；必须重新读取，不按 +1 推算。
