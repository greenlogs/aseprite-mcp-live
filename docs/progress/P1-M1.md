## 实际完成了什么

新增 `backends/live.py`，通过 FastMCP lifespan 绑定工具使用的同一 Executor。回环端口默认随机、启动 token 随机；扩展主动 hello，服务 welcome，拒绝错误 token、协议/API 不兼容和第二活动连接。断开清理会话与等待请求，超时不自动重发，不回退 CLI。stdio stdout 仅用于 MCP。

扩展由 package.json 注册 main.lua，init/exit 与连接/断开菜单管理 bridge.lua；设置对话框选择服务发现 JSON。连接对象、回调、去重缓存保持引用；重连建立新 session，旧 session 不能执行。此模块仅协商 list_documents 无副作用读取，文档注册和内容工具待 M2。
