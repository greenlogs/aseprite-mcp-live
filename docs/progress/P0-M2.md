## 实际完成了什么

建立 `core/protocol.py` 严格请求/目标/操作/结果/错误/PNG 模型、握手与版本能力校验；`config.py` 冻结回环配置、随机启动 token 和全部可配置上限。`core/execution.py` 定义 Backend、显式路由、单会话拒绝、多请求串行、关联校验、容量/TTL 去重及错误映射。未连接实时请求不调用 CLI。

`backends/cli.py` / `cli.lua` 完成公共执行接口的文档读取和批次绘图：JSON 传参、预检查、事务、副本图像赋回、中文路径、nonce 回执、临时文件隔离、产物校验及原子替换；检测执行期间源文件变化并拒绝覆盖。复用上游 commands 受控进程路径，未重写所有上游工具。

`server.create_server()` 建立 core（默认 9）、cli（115 兼容工具 + cli_execute）、all（125）配置；原始 Lua 额外显式开启，旧工具原名/参数保持。新工具错误经 ToolError 返回 MCP isError。当前仅连接状态可正常查询，实时内容工具无连接时明确失败；没有创建 WebSocket listener 或扩展。

字段、样例、默认值、兼容差异和实施位置见 [协议 v1](../development/PROTOCOL.md) 与[样例](../development/protocol-v1.examples.json)。

## 接口与兼容变化

协议版本 1，帧从 1、坐标从 0、RGBA 四字节整数；批次引用为 `{kind: ref,value: ref}`，实标识为 `{kind: id,value: id}`。实时内容请求附预期修订；内容/上下文修订单独维护。回环启动 token、协商能力、错误及 PNG base64 约定已冻结。默认上限 8 MiB 消息、256 操作、262144 像素、4 MiB PNG、30 秒超时、256 缓存项/120 秒，理由见协议。

公共 CLI 只支持 info/apply，不接收实时修订；索引图层 id 不等于实时会话标识。旧 CLI 文本错误及执行行为仍保持兼容，未宣称所有 115 个工具已有公共适配器的回执保证。默认暴露改为 core；使用者需显式配置 CLI。MCP 1.6.0 的私有注册表兼容接缝集中在 server.py，并由枚举/调用测试覆盖。
