## 实际完成了什么

用户报告 Preview 已有图像，主画布需缩放等交互才显示。现有 WebSocket 回调修改 Cel 后没有显式刷新。

editor.lua 的 with_target 增加内部 refresh 参数，绘图批次、动画批次和撤销/重做启用。事务提交或回滚、活动文档/图层/帧恢复后，每次操作只调用一次 app.refresh()，不放在操作或像素循环内。预检拒绝、读取、保存及去重直接返回不增加刷新。回滚后仍刷新，原事务错误优先返回，刷新失败不会覆盖原始错误。

测试在独立编辑器中加载带 app 代理的相同 editor.lua；代理记录刷新次数和活动上下文，同时调用真实 app.refresh()。所有其他 API 读写转发到真实 Aseprite；探针不进入产品扩展。
